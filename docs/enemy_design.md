# NYPD — Enemy Design

> Статус: v0.1, черновик по итогам обсуждения. Конкретный бестиарий/баланс цифр — дозаполнить позже.

## Ключевой принцип
Враги — это инструмент передвижения, а не боевая преграда. Большинство — фодер (умирают за 1–2 удара), их главная функция — давать дополнительные способы редиректа движения и заполнять флоу-коридоры интерактивом, а не требовать тактического боя. Это прямое продолжение design pillar "скорость = урон" из gameplay_design.md, и оно сознательно снижает скоуп боевого AI — разумный компромисс для небольшой команды.

## Резолюция: "физические vs астральные" враги
Урон не разделён по типам — все враги получают урон одинаково от любой атаки. Заряженная атака (катана в ножнах → прожектайл-слэш) отличается тем, что **не наносит урон разрушаемым пропсам/окружению**, а не тем, что она специально эффективна против духов. Формулировка "техника против астральных сущностей" может остаться чисто лорным/VFX-флейвором либо быть убрана полностью — решение отложено (см. открытые вопросы).

## Архетипы по функции передвижения
| Архетип | Эффект для игрока | Статус |
|---|---|---|
| Bounce (батут) | Приземление сверху → подброс вверх | ✅ подтверждено (слайм) |
| Grapple node (точка зацепа) | Враг в воздухе, зацеп крюком-кошкой → полёт/отпрыг | ✅ подтверждено (призрак) |
| Ranged irritant (раздражитель) | Стреляет снарядом, требует подкат-уклонение без полной остановки | Тентативно |
| Melee fodder (рядовой) | 1–2 удара, дэш/атака насквозь без потери скорости | Базовый, implied |
| Launch/repel (пинбол) | Удар по врагу → отбрасывает игрока в противоположную сторону с инерцией | Предложение на добор |
| Chain extender | Как grapple node, но продлевает дальность/время полёта крюка | Предложение на добор |

**Идея для стиль-системы**: бонус за чейн из *разных* архетипов подряд (грэппл → баунс → дэш-килл → пинбол), а не за повтор одного типа — аналог "style decay от повторов" в DMC, реализованный через выбор маршрута/целей, а не только через комбо-инпуты.

## Тематический ростер (черновик, требует привязки к конкретным уровням)
- **Слайм** — bounce. Низший дух, набравший форму после хэллоуинской ночи.
- **Призрак (юрэй?)** — grapple node. Можно усилить вариант с "цепным" подтипом для длинных воздушных цепочек.
- **Они (демон)** — кандидат на launch/repel: крупный, отбрасывающий враг.
- **Каракаса-обакэ / цукумогами** (анимированные предметы) — потенциальный архетип под визуальный стиль японского Хэллоуина, функция не определена.
- **Рядовые люди (бывшие самураи/якудза-конкуренты)** — melee fodder, человеческая угроза на фоне политической турбулентности эпохи Мэйдзи, не мистика.
- Полный бестиарий — дозаполнить по мере проработки уровней.
