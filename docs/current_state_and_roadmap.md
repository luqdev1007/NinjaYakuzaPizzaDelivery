# NYPD — Current State & Roadmap

> Статус: v0.1, снимок по итогам разбора кода и предыдущих решений.

## Что уже реализовано (по результатам code review)
### Герой
- Движение: бег с разгоном/торможением, прыжок с контролем по времени зажатия, доп. воздушные прыжки, wall jump
- Дэш (контроль по времени, не работает в падении), подкат/слайд, механика наклонных поверхностей (slope slip/slide/jump)
- Глайд/парашют (открытие на пробел в падении)
- Пике/плендж с уроном по приземлению
- Зацеп за стену (wall hang) с медленным сползанием
- Крюк-кошка (grapple)
- Обычная атака, заряженная slash-атака (sheath→release), double-attack (задел под будущую боевую прокачку), воздушный juggle
- Инвентарь (использование/переключение предметов, throwables/potions)
- I-frames на атаке, hit-stop, тело наносит урон на скорости (дэш/пике)
- Lifecycle: spawn/death процессы с таймерами

### Враги
- **Призрак** — полностью реализован (здоровье, контактный урон, knockback, смерть, флаг "grappled target")
- **Слайм** — НЕ реализован, код закомментирован, помечен `REWORK`, фабрика возвращает `null`. Баунс-механика из enemy_design.md пока не существует в коде.

### Метасистемы/UI
- Кошелёк с реактивными переменными по каждому типу валюты — инфраструктура готова под дуальную экономику (золото/осколки душ)
- Полноценный MVP+анимации для попапов (confirm, audio/graphics/language/keybindings settings)
- Главное меню: кнопки на додзё/шоп/лидерборд существуют, но управляются через прямой `SetActive`, не через Presenter
- Прогрессия по уровням, сохранение/загрузка (JSON, локальный файл)
- Стиль/ранк-система и секретки уже регистрируются как сервисы (`RankStyleService`, `StyleEvaluator`, `SecretChestCollectService`, `LevelResultService`) — степень готовности уточнить дополнительно

## Известные технические риски (приоритет — high)
1. Основной геймплейный луп на переменном таймстепе + coroutine-таймеры в Dash/Slide/Inventory — несовместимо с детерминированными ghost-replay/лидербордами. Чем раньше исправить — тем дешевле.
2. Три leftover `NotImplementedException`-заглушки в разных частях кода.
3. `EntityAPIGenerator` на `[InitializeOnLoadMethod]` — риск нестабильных домен-релоадов.
