2.1 ГЛАВНАЯ НАХОДКА: 58.08 МБ текстур в билде НЕ сжаты блочно
-------------------------------------------------------------
Метрика: эффективные байты на пиксель (packed / (ширина*высота после Max Size)).
BC1/DXT1 = 0.5 bpp, BC3/DXT5 = 1.0 bpp, BC7 = 1.0 bpp, RGB24 = 3.0, RGBA32 = 4.0.

  bpp > 1.5 (то есть НЕ блочно сжато):  58.08 МБ в 71 ассете
  если бы все они были BC3/BC7:         14.98 МБ
  потенциал:                            43.10 МБ

Три независимые причины, по убыванию вклада:

  а) РАЗМЕРЫ НЕ КРАТНЫ 4  ->  34.96 МБ в 59 ассетах
     Unity молча откатывается с DXT/BC на RGBA32 или RGB24, если хоть одна
     сторона не делится на 4. В инспекторе при этом честно написано
     "Compression: Compressed" - и это ложь по факту.

  б) ЯВНЫЙ Compression = Uncompressed  ->  13.12 МБ в 7 ассетах
  в) PLATFORM OVERRIDE в RGBA32/RGB24  ->  11.42 МБ в 8 ассетах
     (пункты б и в частично пересекаются с а)

2.2 ТЕКСТУРЫ, У КОТОРЫХ MAX SIZE СИЛЬНО БОЛЬШЕ ЭКРАННОГО РАЗМЕРА
-----------------------------------------------------------------
Опорные данные для расчёта (взяты из проекта, не выдуманы):
  - Cinemachine/Camera orthographic size = 8 во всех уровневых префабах
    (BaseScene, DownAndUp, Village, VillageToChurch) и в Gameplay.unity.
    Значит видимая высота = 16 world units. При 1080p это 67.5 px на unit.
  - CanvasScaler в GameplayUIRoot и MainMenuUIRoot: ScaleWithScreenSize,
    reference 1920x1080, match 0.5.

  Shuriken.png                1800x1013, PPU=1500 -> 1.2 x 0.675 units
    -> на экране 81 x 46 px при 1080p (162 x 91 при 4K).
    В билде 6.956 МБ. Пересемплирование примерно в 22 раза.
    Max Size 128 дал бы 128x72 -> ~0.011 МБ. Экономия 6.94 МБ.

  Shuriken_upgrade.png        1800x1013, PPU=100.
    Единственная ссылка на неё - поле Icon в
    _Project/Resources/Configs/Meta/Shop/ShurikenDamageUpgradeConfig.asset,
    то есть это ИКОНКА ТОВАРА В МАГАЗИНЕ. В ShopItemView.prefab
    ItemIconImage растягивается по родителю (sizeDelta -30,-30), реальный
    размер порядка 100-150 px. В билде 6.956 МБ.
    Max Size 256 -> ~0.06 МБ. Экономия 6.9 МБ.

  MainHeroAtlas.spriteatlasv2  20.001 МБ, ~5 страниц 2048x2048 BC3.
    Исходники: 101 спрайт в Sprites/Gameplay/MainHero/Actions,
    типовой кадр 232x439 ... 362x483, PPU = 300.
    Проверка по префабу MainHero.prefab: SpriteRenderer "View",
    sprite Idle__000_0 rect 232x439, ppu 300, bounds 0.77 x 1.46 units.
    1.46 units * 67.5 px/unit = 98.6 px на экране при 1080p,
    197 px при 4K. Исходник 439 px - пересемплирование 4.45x при 1080p
    и 2.2x при 4K.
    Половинное разрешение исходников (при одновременном снижении
    spritePixelsPerUnit с 300 до 150, чтобы мировой размер не поехал)
    даёт атлас ~5 МБ. Экономия ~15 МБ.

ViewsFactory: захардкоженных путей вида "UI/..." через прямой Resources.Load

      вместе с пересчётом spritePixelsPerUnit. Только точечно и
      с проверкой, как в A3/B2.
